# Third-party software and data

This project is glue and policy. It does not bundle anyone else's program or data: everything below is **downloaded
on your machine at install time** (programs are checked against a pinned SHA-256 first). Each belongs to its authors
and is used under its own licence; please read those before redistributing anything.

## Programs fetched by `install-components.sh`

| Component | Used for | Licence (as published by the project) |
|---|---|---|
| [Just Perfection](https://gitlab.gnome.org/jrahmatzadeh/just-perfection) v37 | hides the top bar and the dash | GPL-3.0 |
| [Colorblind Filters](https://github.com/G-dH/color-blind-filters) v22 (G-dH) | the grayscale screen filter | GPL-3.0 |
| [Focused Window D-Bus](https://github.com/flexagoon/focused-window-dbus) v8 (flexagoon) | lets ActivityWatch see the active window on Wayland | MIT |
| [ActivityWatch](https://activitywatch.net) (aw-tauri 0.14.0) | measures how time on the computer is spent | MPL-2.0 |
| [awatcher](https://github.com/2e3s/awatcher) 0.4.0 | the ActivityWatch window and idle watcher for Linux | MPL-2.0 |

`install-components.sh` makes **one small edit** to the downloaded Colorblind Filters extension on your machine: it
removes the line that adds a clickable eye icon to the top bar, so the grayscale cannot be switched off by a stray
click. The edited copy stays under that extension's GPL-3.0 licence and is never committed to this repository.

## Operating-system pieces that are only referenced

The ZorinGrey-Dark theme and icons, and the Zorin extensions the environment switches off, come from Zorin OS and
GNOME. They are named in `lib.sh` but not shipped.

## Datasets used to build the vault's question bank

`vault/fetch_bank.sh` downloads these and converts them locally. They are for **your personal use**; the generated
bank is deliberately not part of this repository (it would also reveal the answers).

| Dataset | Licence |
|---|---|
| [AQuA-RAT](https://huggingface.co/datasets/deepmind/aqua_rat) (DeepMind) | Apache-2.0 |
| [ARC](https://huggingface.co/datasets/allenai/ai2_arc) (Allen AI) | CC-BY-SA-4.0 |
| [LogiQA 2.0](https://github.com/csitfun/LogiQA2.0) | CC-BY-NC-SA-4.0 |
| [MMLU](https://huggingface.co/datasets/cais/mmlu) (high-school and elementary subjects) | MIT |
| [RACE](https://huggingface.co/datasets/ehovy/race) | non-commercial research use |
| [SciQ](https://huggingface.co/datasets/allenai/sciq) | CC-BY-NC-3.0 |

About a third of the bank is generated by this project's own code (arithmetic, series, syllogisms, kinship, tables).
